iPhone 组件
  • 底部 Tab Bar 四页签
  • 迷你播放器常驻歌曲列表上方
  • 全屏播放页：圆盘封面 + 歌词
  • 搜索栏 + 筛选瓷片
  • 歌曲行：封面 + 标题 + 时长
  • 均衡器跳动动画
iPad / Mac 组件
  • NavigationSplitView 侧栏布局
  • 侧栏：资料库分类 + 播放列表
  • 底部播放条：进度 + 控制 + 音量
  • Mac 窗口工具栏：红黄绿按钮
  • 快捷键：空格播放 ← → 切歌
设计原则
  • 留白为主，元素精简
  • 钴蓝为点睛，青瓷为辅色
  • 瓷白底色，温润如玉
  • 宋体标题，无衬线正文
  • 细线分隔，不用阴影
  • 圆角克制，最大 12px
交互细节
  • 点击歌曲：播放 + 均衡器动画
  • 长按：弹出操作菜单
  • 拖拽排序播放队列
  • AirDrop 原生分享
  • 锁屏控制 + 通知中心
  • 正在播放封面旋转动画
