# 均衡器工作原理

## 一句话说明

均衡器（Equalizer，EQ）把一段音频按频率划分为多个范围，并分别增大或减小这些范围的能量。它不会“创造”原始文件中不存在的细节，而是改变低音、中音和高音在听感中的相对比例。

例如，将 64 Hz 提高 4 dB 会让鼓点和贝斯更有力量；将 2 kHz 提高 2 dB 通常会让人声、吉他和咬字更清晰；将 8 kHz 降低 3 dB 则可减轻齿音和刺耳感。

## 音频与频率

数字音频可以看作每秒记录许多声音振幅的序列。任何一段音乐都由不同频率的振动叠加而成：

| 频率范围 | 常见听感或乐器 |
| --- | --- |
| 20–60 Hz | 次低音、低频震感 |
| 60–250 Hz | 鼓点、贝斯、温暖感 |
| 250 Hz–1 kHz | 人声与乐器的厚度 |
| 1–4 kHz | 人声清晰度、存在感 |
| 4–8 kHz | 拨弦、军鼓、齿音 |
| 8–20 kHz | 空气感、明亮度 |

清音的十段频率为 32、64、125、250、500、1k、2k、4k、8k、16k Hz。每段不是只影响一个精确频率，而是以该频率为中心、向两侧逐渐衰减地影响一个范围。

## 分贝和增益

均衡器使用 dB（分贝）表示相对增益，而不是线性百分比。振幅关系为：

```text
线性振幅倍率 = 10 ^ (dB / 20)
```

因此：

| 调整 | 振幅约为原来的 |
| --- | ---: |
| +3 dB | 1.41 倍 |
| +6 dB | 2 倍 |
| -3 dB | 0.71 倍 |
| -6 dB | 0.5 倍 |

清音将单频段和预放大的范围限定为 -12 至 +12 dB。这个范围足以明显改变听感，同时比无上限调节更能防止失真和意外的极端音量。

## 参数均衡器如何处理声音

清音采用参数均衡器（parametric EQ）。每一个频段实质上是一个数字滤波器：输入音频经过滤波器后，该滤波器只对中心频率附近的声音应用指定增益，输出再进入下一个频段。

每个频段有三个关键参数：

| 参数 | 在清音中的配置 | 作用 |
| --- | --- | --- |
| 中心频率 | 固定为十个标准频段 | 决定调整的主要区域 |
| 增益（gain） | -12 至 +12 dB | 决定增强或削弱程度 |
| Q 值（bandwidth） | 1.0 | 决定影响范围的宽窄；Q 越大，影响越窄 |

十个滤波器按顺序串联：

```text
原始 PCM 音频
  -> 32 Hz 滤波器
  -> 64 Hz 滤波器
  -> ...
  -> 16 kHz 滤波器
  -> 预放大
  -> 输出设备
```

滤波器处理的是解码后的 PCM 样本，不是直接修改 MP3、M4A 或 FLAC 文件。原文件不会被写入或损坏，关闭均衡器即可回到未处理的声音。

## 预放大与削波保护

多个频段同时提升时，叠加后的波形可能超过数字音频可表示的最大范围。超过范围的波峰会被截平，产生刺耳的削波失真（clipping）。

预放大（preamp）是所有频段之后的总增益，用于为频段提升预留空间。例如用户将几个频段提高 4 至 6 dB 时，建议将预放大降低约 3 至 6 dB。

第一期实现规则：

1. 用户手动设置预放大，范围为 -12 至 +12 dB。
2. 选用有明显提升的预设时，模板应自带负预放大以提供余量。
3. 后续可增加“自动防削波”选项：根据最大的正增益自动下调预放大。
4. 均衡器关闭时，绕过整个 EQ 节点；不改变用户保存在设置中的数值。

即使没有数字削波，过高的总音量也可能令耳机、扬声器或耳朵产生失真。因此均衡器不应被用作音量放大器。

## 在清音中的运行链路

清音只处理本地音乐，因此可以在应用自己的音频引擎中完成完整链路：

```text
本地 MP3 / M4A / WAV / AIFF / FLAC
    -> AVAudioFile 解码为 PCM
    -> AVAudioPlayerNode
    -> AVAudioUnitEQ（10 个 parametric bands）
    -> AVAudioEngine.mainMixerNode
    -> 系统音频输出
```

`AVAudioUnitEQ` 的每个 `AVAudioUnitEQFilterParameters` 对应一个频段。应用预设或拖动滑杆时，清音仅更新该频段的 `gain` 属性；音频引擎保持运行，因此声音会实时变化而不需要暂停或重新加载歌曲。

预放大映射到 EQ 节点的 `globalGain`。开关映射到效果节点的 `bypass`：启用时处理音频，关闭时音频绕过 EQ 节点，用户配置仍被保留。

## 预设的本质

预设不是特殊的音频算法，而是十段增益和预放大的一组命名数值。例如，“低音增强”会提升 32、64、125 Hz，同时适当降低预放大；“古典”通常会保持较温和的曲线。

当用户选择预设时，清音将模板复制进当前 `EqualizerSettings` 并应用到节点。当用户手动拖动任何一个频段或预放大时，预设名称变为“自定义”，以准确反映当前曲线。

## 采样率限制

数字音频能够表示的最高频率受采样率的一半限制（奈奎斯特频率）。例如 44.1 kHz 音频的上限为 22.05 kHz，足以支持 16 kHz 频段；若某个文件采样率过低，音频引擎应跳过或下调高于其奈奎斯特频率的频段，避免无效配置。

## 听感注意事项

- 小幅调整通常优于大幅提升。先尝试 +/- 2 至 3 dB。
- 优先削减不想要的频段，而非持续提升其他频段，可保留更多音量余量。
- 不同耳机、扬声器和房间环境的低频差异很大，预设应作为起点，而非固定的“正确声音”。
- 人耳对不同频率的敏感程度随音量变化；低音量下适量低频与高频提升可能更自然，但高音量时同样的设置可能过于刺激。

## 与音量控制的区别

音量控制会等比例放大或减小全部频率；均衡器改变的是频率之间的比例。两者可以同时使用，但建议先通过均衡器获得平衡的听感，再使用播放器音量控制实际响度。
